5 · What's still open

  • Sign-in. Decisions name a self-declared role. That's stated on screen; a pilot needs sign-in and a durable database.
  • Server memory on Vercel. Simulations, the review queue and the decision log live on one server instance and can disappear when it recycles. Fine for a demo, not for a pilot.
  • Two new triage cues are untested on history. 'Waiting times … N days' and 'forecast to hit / make landfall' changed nothing in the back-test because no relevant historical signal uses those phrasings. Watch them in the pilot's weekly review.
  • The chat is still rule-based. It now asks back instead of guessing, but new phrasings outside its patterns get a clarification, not an answer.
